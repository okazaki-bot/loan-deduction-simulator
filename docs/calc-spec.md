# 住宅ローン控除計算ツール2026v1 — Web版 計算仕様書

出典: `ローン控除計算ツール2026v1.xlsm`（ライフプランアドバイザー協会 / 住宅ローン控除ソフト）
抽出方法: openpyxl 3.1.5（`data_only=False`）で全シート・全セルの数式を書き写し。生ダンプは `docs/raw-cells/*.txt`。
制度前提: **令和8年度税制改正（2026年1月〜2030年12月入居・控除率0.7%・控除期間13年）**、および税額計算は**令和7年度改正（基礎控除・給与所得控除の見直し）**を反映。

> 本仕様書のセル参照はすべて実ファイルの数式そのままである。推測箇所・矛盾箇所は末尾「未解決事項」に列挙した。

## 0. シート一覧とデータフロー

| シート | 役割 | 主なIN / OUT |
|---|---|---|
| `源泉徴収票` | **主入力**（世帯主=左 B〜BW列 / 配偶者=右 CB〜EW列）+ 住民税出力 | 給与収入・保険料・扶養・均等割・所得UP率を入力。給与所得控除後金額・所得税額・住民税を出力 |
| `基本入力` | 補助入力（20歳未満・ひとり親・寡婦・障害者・勤労学生・配偶者有無・級地区分） | 源泉徴収票のマーク欄を1/0フラグ化 |
| `設定` | 定数テーブル（生保/年金/介護保険料の段階計算、人的控除額、配偶者特別控除表） | 各控除額の元データ |
| `税率等` / `税率等B` | 住民税所得割・調整控除・均等割・非課税判定・所得税速算・寄附金控除の計算エンジン（本人 / 配偶者） | `税額計算`へ供給 |
| `税額計算` / `税額計算B` | 住民税額・所得税額・復興税の最終集計（本人 / 配偶者） | 源泉徴収票の税額欄へ返す |
| `所得控除` / `所得控除B` | 10種類の所得控除を住民税/所得税それぞれで集計（本人 / 配偶者） | `税額計算`の所得控除額 |
| `借り入れ比率` | **住宅・ローン入力**（土地/建物金額・自己資金・持分比率・住宅区分・子育て世帯・金利・年数）+ 夫婦按分 | 借入限度額の区分、返済表への融資額 |
| `資金返済表(世帯主)` / `(配偶者)` | ローン償却表（PMT法）。各年末元金残高 F3〜F15 を算出 | 4住宅シートの年末残高 |
| `認定住宅` `ZEH水準` `省エネ基準` `一般住宅` | 住宅4種 × 13年の控除額計算（4種はパラメータ違いで同構造） | `減税額一覧表`へ |
| `減税額一覧表` | 世帯主/配偶者 × 住宅4種 × 13年 の控除額を集約 | 最終出力 |

**主計算チェーン（上流→下流）:**

```
源泉徴収票(給与収入 P10 等)
  └→ 所得控除(住民税D列/所得税J列 の10控除を集計) ─┐
  └→ 給与所得控除後金額 AE10 ────────────────────┤
                                                   ├→ 税額計算(課税標準→所得割/所得税額)
  └→ 均等割 O61/O62 ───→ 税率等(均等割・調整控除)──┘        └→ 住民税額・所得税額
                                                                     ↓
借り入れ比率(住宅区分/子育て → 借入限度額)  資金返済表(年末残高 F3-F15)
                          └────────┬───────────────────┘
                                4住宅シート(13年 × 控除額 = 所得税控除 + 住民税控除)
                                     ↓
                                減税額一覧表(世帯主/配偶者 × 住宅4種)
```

## 2. 所得の計算

### 2.1 給与所得控除後の金額（令和7年改正）

`源泉!AE10`（世帯主） / `源泉!DE10`（配偶者）:

```
AE10 = MAX( P10 - 給与所得控除 - BQ34 , 0 )

給与所得控除 =
  IF P10 < 1,900,000  → MIN( MAX(P10,0), 650,000 )
  ELIF P10 < 3,600,000 → P10 - ROUNDDOWN(P10/4000,0)*2800 + 80,000
  ELIF P10 < 6,600,000 → P10 - ROUNDDOWN(P10/4000,0)*3200 + 440,000
  ELIF P10 < 8,500,000 → P10*0.1 + 1,100,000
  ELSE                 → 1,950,000
```

- `BQ34`（世帯主）/`EQ34`（配偶者）= 所得金額調整控除額（空＝0）。
- 最低控除額 **650,000**（令和7年改正で55万→65万）。上限 1,950,000。
- **注意**: 4住宅シートの将来投影でも同一式が `AY14` 等で再現される（§5.3）。

## 3. 所得控除（`所得控除` / `所得控除B`）

D列 = **住民税**控除額、J列 = **所得税**控除額。合計は `D52`（住民税）/`J52`（所得税）。
配偶者版 `所得控除B` は源泉徴収票の配偶者列（+78列相当）と基本入力G列・級地D29を参照する以外は同一。

### 3.2 生命保険料控除（`設定`シート）

新契約・旧契約の段階計算を「一般生保」「個人年金」「介護医療」の3カテゴリで実施。
所得控除!B12/C12/D12/B14/C14 が各保険料入力（源泉徴収票 row25 の値）。

**住民税の段階（旧契約・一般生保 例, 設定G4:I7）:**
| 支払額 | 控除額（住） |
|---|---|
| 15,000円以下 | 全額 |
| 15,000超〜40,000 | 支払/2 + 7,500 |
| 40,000超〜70,000 | 支払/4 + 17,500 |
| 70,000超 | 35,000 |

**所得税の段階（旧契約・一般生保, 設定L4:N7）:**
| 支払額 | 控除額（所） |
|---|---|
| 25,000円以下 | 全額 |
| 25,000超〜50,000 | ROUNDUP(支払/2)+12,500 |
| 50,000超〜100,000 | ROUNDUP(支払/4)+25,000 |
| 100,000超 | 50,000 |

**新契約の段階（一般生保・個人年金・介護医療 共通形）:**
- 住民税: ≤12,000 全額 / 12,000〜32,000 ROUNDUP(支払/2)+6,000 / 32,000〜56,000 ROUNDUP(支払/4)+14,000 / 56,000超 28,000
- 所得税: ≤20,000 全額 / 20,000〜40,000 ROUNDUP(支払/2)+10,000 / 40,000〜80,000 ROUNDUP(支払/4)+20,000 / 80,000超 40,000

**カテゴリ集約（設定 F44:J47 住民税 / K44:N47 所得税）:**
```
一般生保(住)   J44 = MAX( 旧計H44, MIN(新G44+旧H44, 28000) )
個人年金(住)   J45 = MAX( 旧計H45, MIN(新G45+旧H45, 28000) )
介護医療(住)   J46 = SUM(介護新旧)          （上限28,000内）
```

## 8. 未解決事項・要注意点

1. **将来投影のUP率セルにコピペ由来の食い違い（4住宅シート共通）**
   - 世帯主の11〜13年目収入 `AT24 = AT23*(1+源泉!AB64/100)`、`AT25 = …*源泉!AB65`、`AT26 = …*源泉!AC66` を参照。`AB64/AB65/AC66` は**入力欄が存在せず空＝0**のため、11〜13年目は収入成長が止まる（＝UP率が効かない）。1〜10年目は `AB63` を使用。**意図的か不明。Web版では要判断**（全年 `AB63` を使うのが素直）。
   - 配偶者シートも11〜13年目は `源泉!AB64/AB65/AC66`（＝世帯主列・空）を参照しており、`DA63` を使っていない（明確なコピペミスの疑い）。
2. **所得控除の年次固定**: 4住宅シートの `BD14=源泉!AT10`（所得控除合計）を全13年で固定使用。扶養の増減・保険料変化は投影に反映されない（概算前提）。
3. **住民税からの控除の課税所得ベース**: 4住宅シートは `BI14`（＝投影課税所得）× 5% と 97,500 と引き切れない額の最小。一方 `税額計算!住宅ローン控除` は別ロジック（S15/S16）で、両者は独立。Web版では4住宅シート側のロジック（AG=W+AB）が最終出力に使われる点に注意。
4. **`M29`/`CM29`（住民税から引き切れない住宅ローン控除）と `BF20`/`EF20`（住宅借入金等特別控除の額）**: 源泉徴収票の該当セルは実質未使用（空）。`税額計算!L15` はこれらを参照するが本シミュレーションのメイン経路ではない。
5. **合計式の予約枠**: `所得控除!D52` に `D6`、`J52` に `J6,J22` が含まれるが未定義（医療費控除等の空枠、＝0）。
6. **住民税所得割の税率は一律 市6%/県4%**（政令市の税率調整 8%/2% 等は非対応）。
7. **調整控除・非課税判定・ふるさと納税限度額**は住民税の最終額には寄与するが、住宅ローン控除の年次計算（4住宅シート）には直接は使われない（4住宅シートは独自に所得税・課税所得を再計算）。
8. **フラット35の11年目金利切替**は月々分のみ（`C9`, `C11`＝10年目末残高で再ローン化）。ボーナス分は単一金利。銀行分も単一金利。
9. **端数処理**: 所得税=速算後ROUNDDOWN(-2)、復興ROUNDDOWN(×1.021,-2)、住民税課税標準TRUNC(-3)、均等割月割ROUNDDOWN(/12,-2)。Web実装ではExcelのROUNDDOWN/ROUNDUP/TRUNC/FLOOR/PPMT/IPMT/PMTの丸め・符号仕様を厳密に一致させること。
10. **配偶者控除で老人控除対象配偶者の上乗せ**は非対応（一律 §3.3 の額）。
